# Student Score Analyzer

A simple web application built with Flask to analyze student academic performance. It allows users to manage student records, calculate grades, and visualize performance through charts.

## Features

- Add, update, and delete student records
- Automatic total, percentage, and grade calculation
- Performance visualization using charts
- Search student records
- Responsive user interface

## Built With

- Python
- Flask
- Pandas
- Matplotlib
- SQLite
- HTML
- CSS
- JavaScript

## Getting Started

### Clone the repository

```bash
git clone https://github.com/aravindthiru29/student-score-analyzer.git
```

### Navigate to the project

```bash
cd student-score-analyzer
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
